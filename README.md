# PDF Merger — локальное объединение медицинских PDF по дате

Утилита группирует PDF из каталога `input/` по **дате в начале имени файла** `YYYY-MM-DD-`, объединяет каждый набор и записывает один итоговый файл на дату в `output/`.

**Конфиденциальность:** весь разбор и объединение выполняются **только на вашем компьютере**. Программа не отправляет файлы, содержимое или метаданные в интернет, не использует API, OCR и облачные сервисы. Интернет может понадобиться **один раз при установке Python-библиотеки** через `pip`; исходные медицинские документы никуда при этом не передаются. Репозиторий публичный: **не коммитьте медицинские файлы в GitHub**. `input/`, `output/` и все `*.pdf` добавлены в `.gitignore`.

## Быстрый старт: Windows 10/11

1. Установите [Python 3.10+](https://www.python.org/downloads/) (рекомендуется 3.12 или новее) и Git.
2. Клонируйте репозиторий: `git clone https://github.com/weydreas/PDF_Merger.git`
3. В папке проекта один раз запустите `setup_windows.bat` — будет создано локальное виртуальное окружение `.venv` и установлена библиотека `pypdf`.
4. Положите исходные PDF в папку `input/`, например `2026-05-19-Биохимия.pdf` и `2026-05-19-Гормоны.pdf`.
5. Дважды щёлкните `merge_windows.bat`. Результат появится в `output/2026-05-19.pdf`.

Для ежедневного использования интернет не нужен. Исходные файлы остаются без изменений.

## Пример

```text
PDF_Merger/
  input/
    2026-05-19-Биохимия.pdf
    2026-05-19-Гормоны.pdf
    2026-06-01-ОАК.pdf
    без_даты.pdf
  output/
    2026-05-19.pdf      # Биохимия + Гормоны
    2026-06-01.pdf      # ОАК, побайтовая копия
```

Файл `без_даты.pdf` будет пропущен и указан в отчёте. Невозможные даты (например, `2026-02-30-...`) тоже пропускаются. Дата определяется **только из имени файла**, содержимое PDF не анализируется. При отсутствии префикса дата не угадывается по метаданным.

## Командная строка

Из каталога репозитория, после установки:

```powershell
.\.venv\Scripts\python.exe pdf_merger.py --dry-run
.\.venv\Scripts\python.exe pdf_merger.py
.\.venv\Scripts\python.exe pdf_merger.py --overwrite
.\.venv\Scripts\python.exe pdf_merger.py --recursive
.\.venv\Scripts\python.exe pdf_merger.py --input-dir "D:\Health\input" --output-dir "D:\Health\output"
```

- Без флагов читаются **только PDF непосредственно в `input/`**. С `--recursive` просматриваются вложенные папки; папка результата исключается из обхода.
- Для каждой даты создаётся `YYYY-MM-DD.pdf`. PDF одной даты объединяются в детерминированном порядке по **исходному имени файла**, с учётом регистра и пути при вложенных папках. Порядок показан в консоли перед операцией.
- Один PDF на дату копируется без изменения байтов. Если два и более файла на дату, страницы присоединяются в порядке файлов с помощью `pypdf`.
- **Существующие результаты не перезаписываются по умолчанию.** Для явной замены используйте `--overwrite`; `--dry-run` только показывает план.
- При повреждённом или зашифрованном PDF группа завершается с ошибкой, **не создавая неполного итогового файла**. Остальные даты продолжают обрабатываться; код возврата `1` сигнализирует о частичных ошибках.
- Новые PDF сначала сохраняются во временный файл внутри `output/`, проверяются на соответствие числа страниц, а затем публикуются. Частичные временные файлы удаляются.

### Особенности PDF

Объединение с помощью `pypdf` сохраняет страницы, но не гарантирует исходный вид сложных интерактивных форм, вложений и цифровых подписей: **цифровые подписи объединённых PDF становятся недействительными**. Для юридически значимых подписанных документов используйте оригиналы. Сканы и обычные результаты анализов обычно подходят для объединения.

## Тесты

Тесты используют только искусственные PDF без данных клиентов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Техническая информация

- Python 3.10+, библиотека [pypdf](https://pypdf.readthedocs.io/en/latest/user/merging-pdfs.html), стандартная библиотека Python.
- Программа не открывает сетевых соединений и не загружает исходные файлы на сервер.
- Для обработки на другой машине достаточно клонировать репозиторий и установить зависимости **на этой машине**. Репозиторий содержит только код и пустые директории.
