# PDF Merger — локальное объединение PDF по датам

Windows-утилита с интерактивным **PowerShell-интерфейсом, организованным по образцу Genome**: `start.cmd` открывает PowerShell, проверяет папки, сообщает число найденных PDF и запрашивает подтверждение перед обработкой. Исходные медицинские документы **никогда не загружаются в интернет**.

## Как пользоваться (Windows 10/11)

1. Скачайте/клонируйте репозиторий и **дважды щёлкните `start.cmd`** (или прежний `merge_windows.bat`).
2. **Первый запуск:** если `input` или `output` отсутствует, программа создаст недостающие папки, сообщит об этом и **завершит работу без обработки**. Окно останется открытым до нажатия любой клавиши. Программа не удаляет и не очищает существующие папки.
3. Поместите в `input/` PDF с именами вида `YYYY-MM-DD-Название.pdf`, например `2026-05-19-Биохимия.pdf` и `2026-05-19-Гормоны.pdf`.
4. **Следующий запуск:** программа выведет `Обнаружено PDF-файлов: 2`, затем:

   ```text
   Запустить проверку и объединение?
     [1] Да, запустить проверку
     [0] Нет, выйти
   Выберите действие [1/0]:
   ```

5. Нажмите `1` и `Enter` (или введите `Да`). Начнутся проверка имён PDF и объединение по датам. Готовые файлы появятся в `output/`; будет показан итог по созданным, пропущенным и ошибкам. **Окно всегда удерживается до `Press any key`**, в том числе при ошибках и отмене.

Если `input/` пуста, программа сообщит об этом и завершится без установки зависимостей. Если PDF есть, но пользователь выбирает `0`, никакие файлы не обрабатываются и зависимости не устанавливаются.

### Установка Python

Нужен **Python 3.10+** (из `python.org`, команда `py` или `python`). После подтверждения обработки программа сама создаст локальную среду `.venv`, если её нет. Если библиотека `pypdf` отсутствует, она будет установлена через `pip` (для первоначальной установки может понадобиться интернет; **в pip передаются только требования к библиотеке, не PDF**). Повторная обработка работает офлайн. Также можно настроить окружение заранее через `setup_windows.bat`.

## Пример

```text
PDF_Merger/
  start.cmd
  merge_windows.ps1
  input/
    2026-05-19-Биохимия.pdf
    2026-05-19-Гормоны.pdf
    2026-06-01-ОАК.pdf
    без_даты.pdf
  output/
    2026-05-19.pdf       # Биохимия + Гормоны
    2026-06-01.pdf       # Побайтовая копия единственного PDF на дату
```

Файл `без_даты.pdf` и несуществующие даты вроде `2026-02-30-...` будут пропущены с указанием причины. Порядок файлов внутри даты — алфавитный по относительным именам файлов; для своего порядка используйте `YYYY-MM-DD-01-...`, `YYYY-MM-DD-02-...`. Дата определяется только по имени, PDF-метаданные не читаются для определения даты.

**Повторная обработка:** уже существующие итоговые PDF **не перезаписываются**. Для принудительной замены запускайте Python напрямую с `--overwrite` (см. ниже). Исходные PDF не изменяются.

## Командная строка (без интерфейса)

После создания `.venv` можно вызвать Python напрямую:

```powershell
.\.venv\Scripts\python.exe pdf_merger.py --dry-run
.\.venv\Scripts\python.exe pdf_merger.py
.\.venv\Scripts\python.exe pdf_merger.py --overwrite
.\.venv\Scripts\python.exe pdf_merger.py --recursive
.\.venv\Scripts\python.exe pdf_merger.py --input-dir "D:\Health\input" --output-dir "D:\Health\output"
```

Без `--recursive` обрабатываются PDF только непосредственно внутри `input/`. Результаты записываются атомарно: сначала во временный файл, затем публикуются после сверки числа страниц. Повреждённый или защищённый паролем PDF не создаёт частично объединённого результата; ошибки одной даты не прерывают остальные даты.

### Конфиденциальность и ограничения

Программа работает с медицинскими PDF **локально**; нет API, OCR, телеметрии, удалённой обработки и передачи содержимого. Репозиторий публичный — никогда не добавляйте медицинские PDF в Git. `.gitignore` исключает `input/`, `output/` и все PDF.

Подписи в объединённом PDF становятся недействительными; интерактивные формы и вложения могут сохраниться не полностью. Для юридически значимых подписанных документов используйте оригиналы.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют только сгенерированные пустые PDF. Windows-сценарии первой и повторной установки, меню и удержания окна описаны в `tests/WINDOWS_MANUAL_TEST.md`.
