# Windows UI acceptance checklist

Запускать в отдельном чистом клоне без медицинских данных. Все действия — двойным щелчком по `start.cmd`.

1. **Без папок**. Убедиться, что `input/` и `output/` отсутствуют. Запустить. Обе папки созданы, написано «Рабочие папки подготовлены», Python не запускается, окно держится до нажатия любой клавиши.
2. **Пустая папка**. Запустить повторно. Сообщение «PDF-файлы не обнаружены»; окно держится; `.venv` не создаётся.
3. **Подтверждение**. Положить два искусственных PDF с одной датой. Запустить. Появляется счётчик `2`, пункты `[1] Да, запустить проверку` и `[0] Нет, выйти`.
4. **Отмена**. Ввести `0`. Результат не создан, окно ждёт клавишу.
5. **Запуск**. Запустить снова, ввести `1`. При необходимости создаётся `.venv` и устанавливается `pypdf`. В `output/` создаётся один итог на дату, страницы идут в алфавитном порядке. Окно держится.
6. **Повтор**. Запустить снова с `1`. Существующий итог не перезаписан.
7. **Ошибка/отсутствие Python**. В чистой среде без установленного Python запустить с файлами, нажать `1`. Отображается понятная ошибка и окно держится до клавиши.
8. **Старый ярлык**. `merge_windows.bat` открывает то же меню и тоже не закрывается до клавиши.
9. **Проверка кириллицы**. Убедиться, что кириллические названия папок и PDF корректно отображаются на Windows PowerShell 5.1.

В Git/CI не используются реальные медицинские PDF.
